# ভোটার তালিকা ওয়েবসাইট (PHP + MySQL) — মডার্ন কম্পিউটার

আপনার পুরোনো `index.html` (একলাশপুর ইউনিয়নের ভোটার তালিকা) এখন ডাটাবেস-ভিত্তিক ওয়েবসাইট।

**কেন ভালো:**
- আগে HTML ফাইলের ভেতরেই ৪২ হাজার ভোটারের তথ্য আর পাসওয়ার্ড লেখা ছিল। যে কেউ ফাইল খুলেই সব দেখতে পারত।
- এখন সব তথ্য MySQL ডাটাবেসে থাকে। লগইন সার্ভারে যাচাই হয়, আর পাসওয়ার্ড এনক্রিপ্ট (hash) করে রাখা হয়।
- প্রতিটি অনুসন্ধানে সার্ভার থেকে শুধু ৫০ জনের তথ্য আসে।
- আলাদা আলাদা ইউজার বানানো যায়। কোনো ইউজার বন্ধ বা মুছে ফেলা যায়।
- কে কখন লগইন, অনুসন্ধান বা প্রিন্ট করেছে তার রেকর্ড থাকে।
- ভুল পাসওয়ার্ড বারবার দিলে ১৫ মিনিটের জন্য ব্লক হয়।
- অ্যাডমিন সব ফিল্টার, বিশ্লেষণ ও CSV ব্যবহার করতে পারে। সাধারণ ইউজার শুধু খুঁজতে ও একজনের তথ্য প্রিন্ট করতে পারে।

## apncloud (cPanel) এ সেটআপ — ধাপে ধাপে

### ১. ডাটাবেস বানান
1. cPanel এ লগইন করুন। তারপর **MySQL® Database Wizard** খুলুন।
2. ডাটাবেসের নাম দিন, যেমন `voter`। cPanel নিজে থেকে নামের আগে আপনার ইউজারনেম বসাবে, যেমন `cpuser_voter`।
3. ডাটাবেস ইউজার বানান, যেমন `cpuser_voter`, আর একটি শক্ত পাসওয়ার্ড দিন।
4. **ALL PRIVILEGES** টিক দিয়ে Next চাপুন।
5. ডাটাবেসের নাম, ইউজার ও পাসওয়ার্ড লিখে রাখুন।

### ২. ফাইল আপলোড করুন
1. cPanel → **File Manager** → `public_html` ফোল্ডারে যান।
2. `voter-site.zip` আপলোড করুন। তারপর ডান-ক্লিক করে **Extract** চাপুন।
3. Extract করার পর `public_html` এর ভেতরে `index.php`, `login.php`, `assets`, `inc` ইত্যাদি থাকতে হবে।
   - যদি সব একটি `public_html/public_html` ফোল্ডারে চলে যায়, ফাইলগুলো এক ধাপ উপরে সরিয়ে দিন (Move)।
4. ⚠ পুরোনো `index.html` থাকলে মুছে দিন। ওই ফাইলে সব ভোটারের তথ্য খোলা অবস্থায় আছে।

### ৩. ইনস্টল করুন
1. ব্রাউজারে `https://আপনার-ডোমেইন/install.php` খুলুন।
2. ডাটাবেসের তথ্য দিন।
3. অ্যাডমিন ইউজারনেম ও পাসওয়ার্ড দিন (কমপক্ষে ৮ অক্ষর) → **সেটআপ করুন**।
4. সেটআপ শেষ হলে File Manager থেকে **`install.php` মুছে দিন**।

### ৪. ভোটার ডেটা আমদানি করুন
1. লগইন করুন → **⚙ অ্যাডমিন** → **⬆ ভোটার ডেটা আমদানি**।
2. আপনার কম্পিউটারে থাকা পুরোনো `index.html` ফাইলটি বাছাই করুন → **আমদানি শুরু করুন**।
3. প্রায় এক মিনিটে ৪২,২২০ জন ভোটার ডাটাবেসে ঢুকে যাবে।
   - ফাইলটি আপনার ব্রাউজারেই পড়া হয়। তারপর ১০০০ জন করে করে সার্ভারে পাঠানো হয়, তাই বড় ফাইল আপলোডের সীমায় আটকাবে না।
4. নতুন ইউনিয়নের তালিকাও একই ফরম্যাটের HTML বা JSON দিয়ে আমদানি করা যাবে। আমদানি করলে আগের তালিকা মুছে যাবে।

### ৫. SSL (https) চালু করুন
1. cPanel → **SSL/TLS Status** → **Run AutoSSL**।
2. `public_html/.htaccess` ফাইলে HTTPS এর ৩টি লাইনের শুরুর `#` মুছে দিন।

## ফাইলগুলো
| ফাইল | কাজ |
|---|---|
| `index.php` | ভোটার অনুসন্ধান, বিশ্লেষণ ও প্রিন্ট (আগের মতো দেখতে) |
| `login.php` / `logout.php` | লগইন / লগআউট |
| `admin.php` | ইউজার, ডেটা আমদানি, সেটিংস (দোকানের নাম/ঠিকানা), কার্যকলাপ |
| `api.php` | সার্ভার-সাইড অনুসন্ধান (JSON) |
| `install.php` | প্রথমবার সেটআপ (কাজ শেষে মুছে দিন) |
| `inc/` | কনফিগ ও ডাটাবেস কোড (ব্রাউজার থেকে দেখা যায় না) |

**প্রয়োজন:** PHP 7.4 বা নতুন (8.x ভালো), MySQL 5.7+ বা MariaDB 10.3+। সব সাধারণ শেয়ার্ড হোস্টিংয়ে এগুলো থাকে।

**পাসওয়ার্ড ভুলে গেলে:**
1. cPanel → phpMyAdmin → `users` টেবিল খুলুন।
2. নিজের সারি মুছে দিন। (সব অ্যাডমিন হারালে `users` টেবিল খালি করে দিন।)
3. `inc/config.php` মুছে দিন।
4. `install.php` আবার আপলোড করে চালান। ভোটারের তথ্য মুছবে না।
